Creating language information

Create initial framework

  1. List sources
    • Open Brave and open each source in tabs
    • Arrange source tabs by usefulness
    • List the sources in the xx-refs file
  2. Create spreadsheet
    • Use sources to create spreadsheet.
    • this page creates general category lists & lists code point names
    • order items so they'll come out automatically in the map tables
  3. Create initial picker
    • Create image shape keys
    • Create character shape keys
  4. Create initial set of terms
    • Make xx-globals.js & xx-vocab
    • Preferably a term to cover every sound
    • Tweak the picker keyboard settings, if needed
  5. Create the initial block file & notes skeletons
    • Make block-globals.js
    • Create the character.html file
    • Create the xx-character.html file
    • Create the local xx_make_details and xx_make_maps pages
  6. Create the initial content in xx.html
    • Add the sample
    • Add the usage section from script-features
    • Create the phonology section
    • Fill in the main vowel & consonant sections.
  7. Create xx-details
    • Ensure the spreadsheet is complete! including usage notes
    • Use the local xx_make_details page to create xx-details.html
    • Fill in example terms for xx-details
  8. Build the full information
    • Add extra information to / clean up the xx-details file, and create the main xx.html file information, together
    • Check the typography sections
  9. Create map & summary tables
    • Ensure the xx-details is complete
    • Make the mapping tables using the xx_make_maps page
    • Populate the summary tables from the map table info
  10. Create index and langdata
    • Use charuse UI input to create initial xx-langdata and scriptInfo/xxx.js
    • Make the index
    • Use index to create list of chars for xx-langs.js & add to xx-langdata
    • Add xx-langdata to langs.js & the scriptInfo data to script-features db
  11. Finish off
    • Do the basic features section
    • Add orthnotes & picker to linkdata/link.db
